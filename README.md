# Pac-Man

A story-driven Pac-Man in a single HTML file: 31 floors across three acts, new enemies (Wraith, Slime, Bloodhound, Gargoyle, Spider), three boss fights, and endless roof rounds.

- **Act 1:** climb the Spookscraper to the King Ghost.
- **Act 2:** fall into the basement and beat the Big Blob.
- **Act 3:** climb the sky floors above the throne room to the Skeleton King, the tower's landlord.

Open `index.html` in a browser to play. No build step or dependencies.

**Controls:** arrows / WASD move · Enter select · Esc back · P pause · Space dash · M sound
